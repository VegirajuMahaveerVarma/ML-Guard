# MLGuard v0.1.1 — Alpha

MLGuard v0.1.1 is a maintenance update to the local-first Python library for testing machine-learning model reliability.

## Changes

- Improved the optional scikit-learn adapter's error message when scikit-learn is not installed.
- Added regression coverage for the missing-dependency scenario.
- Excluded virtual environments, caches, and generated build artifacts from the source distribution, keeping the package lightweight.
- Preserved the framework-independent core API and optional scikit-learn integration.

## Available functionality

- Five model reliability checks.
- Classification and regression evaluation.
- Combined validation and metric-based release gates.
- Command-line interface.
- Reproducible regression-case capture and replay.

## Installation

Download the wheel from the GitHub release assets and run:

```bash
python -m pip install ./mlguard_reliability-0.1.1-py3-none-any.whl
mlguard --version

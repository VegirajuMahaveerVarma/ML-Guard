# MLGuard v0.1.0 — Alpha

MLGuard is a local-first Python library for testing machine-learning prediction
reliability and dataset-level performance. This first alpha is intended for
developer evaluation and feedback; APIs may evolve before version 1.0.

## Included

- Five reliability checks for repeated-call stability, noise robustness,
  mean/variance distribution shift, missing values, and model comparison.
- A controlled fault-injection smoke demo covering five intentionally faulty
  toy-model scenarios, plus a repeated synthetic distribution-shift experiment.
- Classification and regression evaluation metrics.
- Combined validation reports and optional performance release gates.
- A local CLI with JSON report output.
- Optional scikit-learn estimator and Pipeline adapter.
- Automated tests and CI for Python 3.10–3.13.

## Known limitations

- Noise and missing-value perturbations currently require numeric features.
- The CLI accepts numeric CSV features and a one-column numeric target file.
- Classification supports single-label binary/multiclass targets; regression
  supports one numeric target per sample.
- Distribution-shift results screen mean and sample-variance changes; they are
  not statistical hypothesis tests and may miss other distribution changes.
- The controlled fault-injection demo and synthetic distribution-shift
  experiment are regression smoke tests, not broad benchmarks or proof of
  production model quality.

## Install

Download the wheel asset from this release and install the downloaded file:

```bash
python -m pip install ./mlguard_reliability-0.1.0-py3-none-any.whl
mlguard --version
```

The wheel filename reflects the proposed distribution name `mlguard-reliability`; verify its availability on PyPI before any PyPI upload. This alpha is intended to be distributed via GitHub Release assets only. No release has been published yet. For development setup and examples, see the repository README.

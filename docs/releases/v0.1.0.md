# MLGuard v0.1.0 — Alpha

MLGuard is a local-first Python library for testing machine-learning prediction
reliability and dataset-level performance. This first alpha is intended for
developer evaluation and feedback; APIs may evolve before version 1.0.

## Included

- Five reliability checks for stability, noise robustness, distribution shift,
  missing values, and baseline/candidate prediction changes.
- Classification and regression evaluation metrics.
- Combined validation reports and optional performance release gates.
- A local CLI with JSON report output.
- Optional scikit-learn estimator and Pipeline adapter.
- Automated tests and CI for Python 3.10–3.13.

## Known limitations

- Noise and missing-value perturbations currently require numeric features.
- The CLI accepts numeric CSV features and a one-column numeric target file.
- Classification supports single-label binary/multiclass targets; regression
  supports one numeric target per sample.
- Feature-distribution shift results are screening signals, not hypothesis
  tests or proof of production model quality.

## Install

Download the wheel asset from this release and install the downloaded file:

```bash
python -m pip install ./mlguard-0.1.0-py3-none-any.whl
mlguard --version
```

For development setup and examples, see the repository README.
